3. Function: Import and Load Stock Data

load_stock_data() reads the symbols from portfolio.txt and downloads historical OHLC (Open/High/Low/Close/Volume/Adjusted) data for each symbol using quantmod::getSymbols(). Each stock’s data is returned as a separate xts/data frame object inside a named list, keyed by ticker symbol.

load_stock_data <- function(portfolio_file = "portfolio.txt",
                            src = "yahoo",
                            from = Sys.Date() - 365,
                            to = Sys.Date()) {

  # Read the stock symbols from the portfolio file, one per line
  symbols <- readLines(portfolio_file)
  symbols <- trimws(symbols)
  symbols <- symbols[symbols != ""]

  stock_data <- list()

  for (sym in symbols) {
    message("Downloading data for: ", sym)

    result <- tryCatch({
      getSymbols(sym,
                 src = src,
                 from = from,
                 to = to,
                 auto.assign = FALSE)
    }, error = function(e) {
      warning("Failed to download ", sym, ": ", conditionMessage(e))
      NULL
    })

    if (!is.null(result)) {
      # Convert xts to a data frame with a Date column and clean names
      df <- data.frame(Date = index(result), coredata(result))
      colnames(df) <- c("Date", "Open", "High", "Low", "Close", "Volume", "Adjusted")
      stock_data[[sym]] <- df
    }
  }

  return(stock_data)
}

The analysis window is fixed to one year (24 Aug 2025 – 24 Aug 2026) so the results are reproducible.

4. Function: Compute Basic Statistics

calculate_statistics() takes a single stock’s data frame (as produced by load_stock_data()) and computes:

  • Moving average (20-day Simple Moving Average of the closing price, via TTR::SMA)
  • Mean closing price
  • Mode closing price (R has no built-in mode() for this, so a helper is defined)
  • Median closing price
  • Standard deviation of the closing price
# Base R has no statistical mode function - define one
get_mode <- function(x) {
  x <- x[!is.na(x)]
  ux <- unique(x)
  ux[which.max(tabulate(match(x, ux)))]
}
calculate_statistics <- function(stock_df, ma_period = 20) {

  close_prices <- stock_df$Close

  moving_avg <- TTR::SMA(close_prices, n = ma_period)

  summary_stats <- data.frame(
    Mean        = mean(close_prices, na.rm = TRUE),
    Mode        = get_mode(close_prices),
    Median      = median(close_prices, na.rm = TRUE),
    SD          = sd(close_prices, na.rm = TRUE),
    Latest_MA20 = tail(moving_avg, 1)
  )

  list(summary_stats = summary_stats,
       moving_average = moving_avg)
}

all_stats <- lapply(stocks, calculate_statistics)

display_stock_data <- function(stock_list, n = 5) {
  for (sym in names(stock_list)) {
    df <- stock_list[[sym]]
    cat("\n=====", sym, "=====",
        nrow(df), "trading days from", format(min(df$Date)),
        "to", format(max(df$Date)), "\n")
    print(head(df, n), row.names = FALSE)
  }
}

5.2 Display computed statistics (table form)

display_statistics <- function(stats_list) {
  combined <- do.call(rbind, lapply(names(stats_list), function(sym) {
    row <- stats_list[[sym]]$summary_stats
    cbind(Symbol = sym, row)
  }))
  rownames(combined) <- NULL
  combined
}

6. Summary

This preliminary stage set up the project scaffolding for the technical analysis project:

  • portfolio.txt holds the five ticker symbols (AAPL, MSFT, GOOGL, AMZN, TSLA).
  • load_stock_data() imports one year of daily prices for every symbol with quantmod and stores each stock as its own data frame.
  • calculate_statistics() computes the 20-day moving average, mean, mode, median and standard deviation of the closing price.
  • display_stock_data(), display_statistics() and the chart loops display the data as tables, line charts and candlestick charts.

These functions will be reused and extended in the next two stages of the project.
